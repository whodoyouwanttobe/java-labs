## Как открыть

IntelliJ IDEA → File → Open → папка `lab2` или `lab3` (не корень репозитория) → «Open as Project».
JDK 21 или новее. Maven сам скачает JavaFX, JUnit и (для лабы 3) Jackson.

- запуск окна: `org.example.Main`, или `mvn javafx:run` в папке лабы;
- тесты: `mvn test` в папке лабы.
