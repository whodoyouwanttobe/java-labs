# Java labs, вариант 4: справочник контактов на префиксном дереве

Бригада: Носов Александр, Казаков Андрей, гр. АВТ-554, НГТУ.

Каждая лаба — отдельный Maven-проект. Следующая лаба — копия предыдущей плюс новое.

| Папка | Что |
|---|---|
| [lab2](lab2) | Trie на массивах, хранилище с `synchronized`, CSV, генератор, окно с деревом, фоновые задачи |
| [lab3](lab3) | ЛР2 + сохранение в JSON и бинарный формат, тесты на готовых файлах |

Открывать в VS Code (Extension Pack for Java) папку `lab2` или `lab3`, не корень репозитория.
Запуск — через Run and Debug, тесты — через панель Testing.
